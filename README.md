# Chandrasekhar Portfolio — V3

Responsive portfolio built with plain HTML, CSS, and JavaScript.

## Run locally
1. Keep `index.html`, `style.css`, and `script.js` in the same folder.
2. Open `index.html` in a browser, or use VS Code's Live Server extension.

## Before publishing
- Replace `YOUR_EMAIL@example.com` in `index.html` with your email address.
- Check the GitHub repository links and ensure the project descriptions match the code in each repository.
- Update the technology list if there are tools you have not used yet.
- Add your third project when you are ready.

## Publish with GitHub Pages
1. Create a repository for the portfolio and upload all three website files.
2. Open the repository's Settings → Pages.
3. Set the deployment source to the `main` branch and the root folder.
4. Save and wait for GitHub Pages to publish the site.
